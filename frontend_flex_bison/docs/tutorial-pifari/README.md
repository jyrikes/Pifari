# Academia Pifari

Site estático em português com 18 aulas. Abra dist/index.html ou sirva dist com um servidor HTTP.

- dist/assets/lessons.js: conteúdo, exercícios e exemplos copiados do projeto Pifari.
- dist/assets/app.js: navegação, pesquisa, progresso local e download de exemplos.
- dist/assets/style.css: layout responsivo.
- dist/index.html: estrutura da página.

O site não executa Pifari no navegador. Os exemplos devem ser executados localmente com ./pifari. Nenhum serviço externo de IA é necessário para ler o curso.
